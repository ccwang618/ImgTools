# 圖片馬賽克工具使用手冊

## 產出檔案

- `add_mosaic.html`：單頁圖片馬賽克工具，可直接用瀏覽器開啟。
- `README_mosaic.md`：本使用手冊。

## 開啟方式

### 方式一：直接開啟

1. 在檔案總管中找到 `add_mosaic.html`。
2. 使用 Chrome、Edge 或其他現代瀏覽器開啟。
3. 選擇圖片後即可開始處理。

### 方式二：用 localhost 開啟

若想用本機伺服器測試，可在此資料夾執行：

```powershell
python -m http.server 8000 
或是
py -m http.server 8000
```

接著在瀏覽器開啟：

```text
http://localhost:8000/add_mosaic.html
```

## 操作流程

1. 點選「載入照片」，選擇要處理的圖片。
2. 圖片中央會自動產生一個預設馬賽克區域。
3. 使用工具列選擇 `▭ 矩形` 或 `⬭ 橢圓`。
4. 拖動區域內部可重新定位；拖動邊角或邊緣控制點可調整大小。
5. 在圖片其他位置點一下，可放置新的預設區域；按住拖曳可從頭繪製新區域。
6. 調整「馬賽克強度」滑桿，數值越高，馬賽克方塊越大。
7. 點擊「套用目前區域」後，該區域會鎖定到圖片上。
8. 依需要繼續新增其他馬賽克區域。
9. 勾選「整張圖片套用馬賽克」後，可一次處理整張照片。
10. 使用「復原」可逐步回退已套用的動作。
11. 完成後點擊「下載圖片」，會輸出 `_mosaic.png` 檔案。

## 適合使用情境

馬賽克適合遮擋照片中的可辨識資訊，例如：

- 街拍或活動照片中的人臉。
- 包裹、文件或商品上的條碼與 QR Code。
- 白板、螢幕、紙本資料中的電話、地址、帳號或個資。
- 需要明確讓觀看者知道「此處已刻意隱藏」的區域。

## 注意事項

- 圖片處理都在本機瀏覽器中完成，不會上傳到外部伺服器。
- 下載檔案固定輸出為 PNG，方便保留馬賽克後的畫質。
- 馬賽克是一種視覺遮蔽方式；若原始圖片含高度敏感資料，建議保留處理後檔案即可，不要一併散布原圖。
- 若圖片解析度很高，套用整張圖片馬賽克時可能需要稍等數秒。
