<add_mosaic>
# 角色: 你是一位精通網頁設計、前端工程與瀏覽器 Web API 的工程師。
# 任務: 請建立一個 `.html` 工具，用來對圖片生成馬賽克 。此工具必須可以直接以本機 HTML 或 localhost 開啟使用。
    - 如何給圖片打馬賽克:
    載入照片後，中心位置會出現一個預設區域。拖動角或邊緣控制點調整大小，或拖動內部重新定位。點擊圖片其他位置放置新區域，或拖動從頭繪製一個。在工具列中選擇 ▭ 矩形或⬭ 橢圓。強度滑桿控制方塊大小——值越高，方塊越大。點擊套用鎖定區域，然後根據需要新增更多區域。勾選整張圖片可一次馬賽克整張照片。使用復原逐步回退，或完成後點擊下載。
    - 何時使用馬賽克:
    馬賽克是遮擋可辨識資訊的標準方式——街拍中的人臉、包裹上的條碼、白板上的電話號碼。塊狀馬賽克圖案會被立即理解為有意遮擋，當你需要讓觀看者知道某個區域已被隱藏時，這是更安全的選擇。它在任何縮放級別下都表現良好，因為方塊網格無論圖片解析度如何都保持清晰。
